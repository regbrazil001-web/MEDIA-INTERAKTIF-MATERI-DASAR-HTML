Materi Pemrograman Web

Pelajari pondasi utama pengembang web modern

1. Pengenalan Web & HTML5 Semantik

HTML (HyperText Markup Language) adalah bahasa standar struktur halaman web. HTML5 mengenalkan elemen semantik seperti <header>, <nav>, <main>, dan <footer>.

<!DOCTYPE html>
<html>
  <head><title>Portofolio Saya</title></head>
  <body>
    <h1>Halo, Saya Siswa SMKN 1 Singkarak</h1>
  </body>
</html>

2. CSS3 & Layouting (Flexbox & Grid)

CSS3 digunakan untuk merancang gaya dan tata letak. **Flexbox** sangat ideal untuk tata letak 1 dimensi (baris atau kolom), sedangkan **CSS Grid** digunakan untuk tata letak 2 dimensi.

/* Contoh Penggunaan Flexbox */
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

3. Responsive Web Design (RWD)

RWD memastikan tampilan web fleksibel saat dibuka di HP, Tablet, maupun Laptop menggunakan Media Queries.

@media (max-width: 768px) {
  .container { flex-direction: column; }
}

Tugas Proyek GitHub

Repository 1: Personal Portfolio Website

Langkah-Langkah Sinkronisasi GitHub

  1. Buat repositori baru di GitHub dengan nama portfolio-website.
  2. Lakukan git init pada folder proyek HTML/CSS portofolio pribadi Anda.
  3. Jalankan perintah commit awal:
    git add .
    git commit -m "Commit awal proyek portofolio"
  4. Hubungkan ke repositori online dan *push* kode program Anda:
    git remote add origin [URL_REPOSITORY_ANDA]
    git push -u origin main
  5. Aktifkan **GitHub Pages** pada menu *Settings* repositori untuk mempublikasikan website secara online.
